# 🍬 죄수의 딜레마 체험 부스 (야탑제 · 심리탐구 동아리)

같이 온 2명이 **각자 다른 기기**(휴대폰·태블릿·노트북)에서 `협력` 또는 `배신`을 고르는 웹 게임이에요.
노트북 한 대에서 서버를 켜면, 같은 와이파이에 있는 휴대폰/태블릿은 브라우저(크롬, 사파리 등)로 바로 들어올 수 있어요. 앱 설치는 필요 없어요.

| 화면 | 주소 | 설명 |
|---|---|---|
| 게임 | `http://주소:3000` | 방 만들기 / 방 참가하기 |
| 부스 모니터 | `http://주소:3000/monitor` | 전체 협력·배신 비율 실시간 집계 (큰 화면용) |
| 관리자 | `http://주소:3000/admin` | 사탕 보상표·라운드 수 바꾸기, 통계 초기화, 방 관리 (기본 PIN **1234**) |

---

## 1. 준비물 설치 (처음 한 번만)

1. **Node.js 설치**: <https://nodejs.org> 에 들어가서 **LTS** 버전을 받아 설치해요. (설치할 때 계속 "다음"만 눌러도 돼요)
2. 설치 확인: 터미널(윈도우는 `명령 프롬프트` 또는 `PowerShell`, 맥은 `터미널`)을 열고 입력해요.
   ```
   node -v
   ```
   `v20.x.x` 처럼 숫자가 나오면 성공!
3. `prisoners-dilemma.zip` 압축을 풀고, 터미널에서 그 폴더로 이동해요.
   ```
   cd 압축푼폴더경로/prisoners-dilemma
   ```
   (팁: 윈도우는 폴더를 연 다음 주소창에 `cmd` 라고 치고 엔터를 누르면 그 폴더에서 터미널이 열려요.)
4. 필요한 부품 설치 (인터넷 필요, 처음 한 번만):
   ```
   npm install
   ```
   ⚠️ **축제 당일 학교 와이파이에 인터넷이 안 될 수도 있으니, 미리 집에서 `npm install` 까지 해 두세요.** 그 다음부터는 인터넷 없이도 돼요. (QR 코드도 인터넷 없이 만들어져요)

## 2. 실행하기

```
npm start
```

그러면 이런 화면이 나와요:

```
========================================
 죄수의 딜레마 체험 부스 서버가 켜졌어요!
========================================
 이 노트북에서:   http://localhost:3000
 다른 기기에서:   http://192.168.0.15:3000   (Wi-Fi)
 관리자 화면:     http://localhost:3000/admin
 부스 모니터:     http://localhost:3000/monitor
```

- **"다른 기기에서" 에 나온 주소**가 휴대폰/태블릿에서 들어갈 주소예요.
- 끄려면 터미널에서 `Ctrl + C`.
- 터미널 창을 닫으면 서버도 꺼져요. 부스 운영 중에는 창을 열어 두세요.
- 서버를 껐다 켜도 진행 중이던 방과 통계는 `data/state.json` 에 저장되어 있어서 그대로 이어져요.

## 3. 축제 당일: 여러 기기로 접속하기 (같은 와이파이)

1. 부스 노트북과 참가자 휴대폰/태블릿을 **같은 와이파이**에 연결해요.
2. 노트북에서 `npm start`.
3. 노트북 IP 주소 확인 (위 "다른 기기에서" 주소가 나오면 이 단계는 건너뛰어도 돼요)
   - **윈도우**: 명령 프롬프트에서 `ipconfig` → "무선 LAN 어댑터 Wi-Fi" 아래 **IPv4 주소** (예: `192.168.0.15`)
   - **맥**: `시스템 설정 → Wi-Fi → (연결된 와이파이) 세부사항` 의 IP 주소, 또는 터미널에서 `ipconfig getifaddr en0`
4. 휴대폰 브라우저 주소창에 `http://192.168.0.15:3000` 처럼 입력 (**https 아니고 http**, 끝에 `:3000` 꼭!)
5. **방화벽 허용**: 윈도우에서 처음 실행할 때 "Windows 보안 경고 - Node.js 액세스 허용?" 창이 뜨면 **개인 네트워크/공용 네트워크 모두 체크 → 액세스 허용**을 눌러요. 맥에서 "들어오는 연결 허용?"이 뜨면 **허용**.
   - 이미 "취소"를 눌렀다면: 윈도우 `Windows 보안 → 방화벽 및 네트워크 보호 → 방화벽에서 앱 허용` 에서 Node.js 를 찾아 체크.
6. **QR 코드**: 방을 만들면 나오는 QR은 자동으로 노트북의 와이파이 IP 주소로 만들어져요. 상대방은 휴대폰 카메라로 찍기만 하면 돼요.
   - 만약 QR 주소가 이상하면(예: 가상 네트워크 주소), 관리자 화면 → **고급 설정 → QR 주소 직접 지정**에 `http://192.168.0.15:3000` 처럼 넣고 저장하세요. (또는 `config.json` 의 `"publicUrl"`)

### 추천 부스 배치
- 노트북(또는 TV 연결): `/monitor` 를 띄워서 전체 통계 보여주기
- 태블릿 2대(공간 A, 공간 B): 한 쪽에서 **방 만들기**, 다른 쪽에서 **방 참가하기** → 코드 4자리 입력
- 또는 참가자 본인 휴대폰으로 QR 찍어서 참가
- 게임이 끝나면 화면에 **각자 받을 사탕 개수**가 크게 나와요 → 동아리원이 보고 나눠주고 **처음 화면으로** 누르기

### 🆘 학교 와이파이에서 휴대폰이 노트북에 접속이 안 될 때
학교/공용 와이파이는 기기끼리 통신을 막아 두는 경우가 많아요(“AP 격리”). 그럴 땐 **휴대폰 핫스팟**을 쓰세요.
1. 동아리원 휴대폰 하나로 **핫스팟(테더링)** 을 켜요. (인터넷 데이터는 거의 안 써요 — 같은 핫스팟 안에서만 주고받아요)
2. 노트북과 참가용 태블릿/휴대폰을 모두 그 핫스팟에 연결해요.
3. 노트북에서 `npm start` 를 **다시** 실행해요 (IP 주소가 바뀌기 때문). 새로 나온 "다른 기기에서" 주소로 접속!
   - 핫스팟은 동시 접속 기기 수 제한(보통 5~10대)이 있어요.
   - 아이폰 핫스팟은 `설정 → 개인용 핫스팟 → 다른 사람의 연결 허용` 을 켜 두고, 그 화면을 열어 둔 상태에서 연결해야 잘 돼요.

## 4. 설정 바꾸기 (사탕 보상표, 라운드 수)

**방법 1. 관리자 화면 (추천)** — `http://주소:3000/admin` → PIN `1234` 입력 → 숫자 바꾸고 **저장하기**.
바꾼 값은 **새로 만드는 방부터** 적용돼요 (게임 중인 방은 그대로).

**방법 2. `config.json` 파일 수정** (서버를 껐다 켜야 적용)

```json
{
  "port": 3000,
  "adminPin": "1234",
  "rounds": 5,
  "payoff": { "CC": 3, "CD": 0, "DC": 5, "DD": 1 },
  "publicUrl": "",
  "cleanupHours": 6
}
```

| 키 | 뜻 |
|---|---|
| `payoff.CC` | 둘 다 **협력** → 각자 받는 사탕 |
| `payoff.CD` | 나 **협력**, 상대 **배신** → 협력한 나(손해 본 쪽)가 받는 사탕 |
| `payoff.DC` | 나 **배신**, 상대 **협력** → 배신한 나가 받는 사탕 |
| `payoff.DD` | 둘 다 **배신** → 각자 받는 사탕 |
| `rounds` | 라운드 수 (기본 5) |
| `adminPin` | 관리자 PIN (축제 전에 바꾸는 걸 추천!) |
| `publicUrl` | QR 주소 직접 지정 (비워 두면 자동) |
| `cleanupHours` | 끝난 방을 몇 시간 뒤에 자동으로 지울지 |
| `port` | 포트 번호 (기본 3000) |

예) 기본값: 둘 다 협력 3/3, 한 명만 배신하면 배신한 쪽 5개·협력한 쪽 0개, 둘 다 배신 1/1.

## 5. 인터넷에 올리기 (선택 · 무료) — Render.com

와이파이 문제를 아예 피하고 싶다면, 인터넷 주소로 배포할 수도 있어요. (단, 참가자 기기가 **인터넷**에 연결되어 있어야 해요 — LTE/5G 도 OK)

1. <https://github.com> 가입 → 새 저장소(repository) 만들기 → 이 폴더 파일들을 업로드 (`node_modules` 폴더는 빼고)
2. <https://render.com> 에 GitHub 계정으로 가입
3. **New + → Web Service** → 방금 만든 저장소 선택
4. 설정:
   - Language/Runtime: **Node**
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance Type: **Free**
5. **Create Web Service** → 몇 분 뒤 `https://이름.onrender.com` 주소가 생겨요. QR도 이 주소로 자동 생성돼요.

⚠️ 무료 요금제 주의점
- 15분 동안 아무도 안 쓰면 잠들어요. 다시 들어가면 **깨어나는 데 30초~1분** 걸려요 → 부스 시작 전에 한 번 열어 두고, `/monitor` 를 켜 두면 계속 깨어 있어요.
- 서버가 재시작/재배포되면 **저장된 방·통계·관리자 화면에서 바꾼 설정이 초기화**될 수 있어요. 보상표는 `config.json` 을 고쳐서 GitHub 에 올리는 게 안전해요.

## 📱 태블릿에서 쓰기 (아이패드 · 갤럭시 탭)

- 세로/가로 모두 돼요. 가로로 두면 보상표가 오른쪽에 따로 나와요.
- **브라우저**: 아이패드는 **사파리**나 크롬, 안드로이드 태블릿은 **크롬**이나 삼성 인터넷을 쓰세요.
- **지원 버전**: iPadOS/iOS **13.4 이상**, 크롬·삼성 인터넷 **80 이상**이면 디자인 그대로 나와요. iOS 12~13.3도 게임은 되지만 글자 크기 등이 조금 다르게 보일 수 있어요.
- **화면 꺼짐 방지**: 부스 운영 중에는 태블릿 자동 잠금을 꺼 두세요. (아이패드: `설정 → 디스플레이 및 밝기 → 자동 잠금 → 안 함`, 갤럭시 탭: `설정 → 디스플레이 → 화면 자동 꺼짐 시간`을 길게)
  화면이 꺼졌다 켜지거나 와이파이가 잠깐 끊겨도 다시 연결되면서 같은 방·같은 라운드로 돌아와요.
- **사파리 개인정보 보호(시크릿) 모드는 쓰지 마세요.** 게임은 되지만 새로고침하면 자리로 돌아가지 못할 수 있어요.
- 같은 태블릿을 다음 팀이 쓸 때는 최종 화면의 **처음 화면으로**를 누르면 돼요.
- (선택) 사파리 `공유 → 홈 화면에 추가` 를 하면 주소창 없이 앱처럼 전체 화면으로 쓸 수 있어요.

## 6. 문제 해결

| 증상 | 해결 |
|---|---|
| 휴대폰에서 접속이 안 돼요 | ① 같은 와이파이인지 ② `http://` 와 `:3000` 을 썼는지 ③ 방화벽 허용 ④ 안 되면 핫스팟 사용 |
| `npm` 명령을 찾을 수 없어요 | Node.js 설치 후 터미널을 **새로** 열어 보세요 |
| `EADDRINUSE` 오류 | 이미 서버가 켜져 있어요. 다른 창을 끄거나 `config.json` 의 `port` 를 3001 등으로 바꾸세요 |
| 새로고침했어요 / 잠깐 끊겼어요 | 괜찮아요! 같은 방, 같은 라운드로 자동으로 돌아가요 |
| 처음부터 다시 하고 싶어요 | 최종 화면의 **처음 화면으로**, 또는 대기실의 **방 취소하기** |
| 통계를 0으로 | 관리자 화면 → **통계 초기화** |

## 7. 개발자용

- 구조: `server.js` (Express + Socket.IO), `public/` (화면: `index.html`, `app.js`, `admin.html`, `monitor.html`, `style.css`), `config.json` (설정), `data/state.json` (자동 저장)
- 상대의 선택은 **둘 다 고르기 전까지 서버가 절대 보내지 않아요** (“골랐는지 여부”만 전달).
- 자동 테스트: `npm test` (서버를 띄워서 방 만들기·참가, 선택 숨김, 4가지 보상 조합, 5라운드, 재접속, 서버 재시작, 동시 2개 방, 관리자 변경, 모니터 통계를 검사)
- 화면 테스트 + 스크린샷: 서버를 켠 상태에서 `BASE=http://localhost:3000 npm run screenshots` (크롬 필요, `screenshots/` 폴더에 저장)
- 태블릿 테스트: `BASE=http://localhost:3000 npm run test:tablet` (아이패드·갤럭시 탭 크기 세로/가로, 크롬+파이어폭스, `screenshots/tablet/` 에 저장)
